# Privacy and public-profile policy

This repository is public because GitHub profile README repositories must be public to appear on the profile.

## Safe to publish

- Public project descriptions
- Public demos and repositories
- Professional social links
- Public-safe email address
- General skills, interests, and location at city/country level

## Keep private

- Passwords, API keys, tokens, certificates, and `.env` files
- Home address and private phone number
- Client data and confidential business information
- Unreleased product plans and internal strategy
- Private family or identity documents

Before publishing a new file, check it for credentials, personal identifiers, private URLs, and embedded metadata.
